# 業務カード：請求まわす（正式名：完了案件の請求書発行）

- 何のため：終わった仕事の代金を、漏れなく、捨めない形で回収する
- トリガー：職長から「上がり」のLINEが来たとき
- 担当：事務A。不在時は社長
- 所要時間の目安：本線20分。追加作業の確認が入ると60分
- 開始してよい条件：上がり連絡がある。見積または追加合意がある。顧客の請求先が台帳にある
- 完了条件：請求PDFを送った。台帳に請求日と入金予定日が入った。フォルダにPDFを置いた
- 成果物：請求書PDF、台帳1行
- 使う道具：LINE、Excel台帳、Misoca、Gmail
- 失敗すると起きること：入金が翌月にずれる。追加分が取れず利益が消える
- 渡せる相手：
- 正社員必須：追加作業を乗せるかの最終判断（現状は社長）
- 外注可：台帳と日報の突き合わせ、Misoca下書き、送付前チェック
- AI可：日報テキストから数量の抜き出し、送付文下書き、チェックリスト照合
- エスカレーション：追加が口頭だけのとき、値引き要求が来たとき、請求先名称が不明なとき → 社長
